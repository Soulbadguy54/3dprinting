## Что можно сделать до пользовательского интерфейса
1. **Рассчитать базовый профиль** по завершённым/дропнутым играм, с весом исходной оценки и признаками жанра. Для одинаковых четырёх критериев учитывать только общий балл, не делать выводы о качестве сценария и графики по отдельности.
2. **Проверить качество профиля офлайн**: скрывать, например, 15–20% оценённых игр, строить ранжирование только по остальным, смотреть, насколько высоко поднимаются действительно понравившиеся; повторить несколько случайных разбиений. Не использовать скрытые данные при расчёте.
3. **Подготовить общий список кандидатов** (игры, которых ещё нет в реальных прохождениях / wishlist конкретного пользователя). Не скачивать целиком IGDB; начать с локальных игр и при необходимости ограниченно расширить по `similar_games` и популярным соседним жанрам.
4. **Задать объяснимые причины:** «похоже на высоко оценённую игру X», «часто нравится тебе этот жанр», «неожиданная находка». Не заявлять персональную точность до её проверки.
5. Зафиксировать UX: где раздел расположен, сколько карточек, undo / история свайпов, отсутствие повторов, управление ошибочными свайпами. До решения по UX **не создавать** таблицы `discovery_events`, API `/api/discover` и отдельный UI.

## Неподвижные действия свайпов, согласованные ранее
- **Влево:** нравится — положительный сигнал, но **не** запись в wishlist.
- **Вправо:** не нравится — отрицательный сигнал, не постоянный blacklist.
- **Вверх:** добавить в существующую системную коллекцию ❤️ «Хочу пройти».
- **Вниз:** подробности игры: описание/скриншоты/трейлер/магазины; это не отрицательная оценка.
- Реальные оценки важнее свайпов. Историю свайпов можно пересмотреть и исправить.

## Первая экспериментальная реализация v1 (feature/discovery-v1)

Вход из «Базы игр» → «Для тебя»; показ первой карточки без дополнительной кнопки «начать»; первое открытие включает пятиступенчатую обучалку, дальнейшие — сразу ленту. Кнопка i перезапускает обучение, браузерный Back закрывает режим. Постер с метаданными, раскрываемая панель с уменьшающейся обложкой слева, описанием и ссылками; жесты как согласованы выше. Решения записываются в таблицу events, undo возвращает карточку и отменяет членство wishlist только если его добавил этот swipe. Признаки текущих рекомендаций — жанры, оценки, рейтинг IGDB; `similar_games`, themes, keywords, offline-validation остаются последующими отдельными задачами.
